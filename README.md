## Подготовка

### Шаг 1

Требуется:
* [yolo11n.pt](https://openproject.mobwal.com/api/v3/attachments/32/content) поместить в корень папки
* [dataset](https://openproject.mobwal.com/api/v3/attachments/31/content) распакавать и поместить в корень папки ./datasets/vxcvxcv
* [dataset 2](https://openproject.mobwal.com/api/v3/attachments/33/content) распакавать и поместить в корень папки ./datasets/electric_meter_1

### Шаг 2

Активировать окружение:

<pre>
python3 -m venv yolo
source yolo/bin/activate
</pre>

<b>Примечание</b>: для деактивации набрать `deactivate`

### Шаг 3

Установить зависимости `pip install -r requirements.txt`
